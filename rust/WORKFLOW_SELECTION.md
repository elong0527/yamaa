# Original native workflow selection

`file_workflow::select` and `select_with_resources` prepare one original native
entry and return either the existing `FileProject` or a complete `FileGraph`.
They accept no activation, study-source or publication port. Ordinary installed
Python/R producer domain dispatch and graph publication remain #1741; this native
preparation boundary does not settle publication lifecycle decision #1866.

The configured entry preserves approved roots and the existing absolute caller
path policy for the environment. A cumulative metadata scope admits existing
configuration captures, environment/lock/definition bytes, preparation copies,
snapshots, aliases, text and work before the first environment root read. Its
limits cannot replace an existing policy or reset spent admission. Both static
graph preparation and selection use the same environment capture service. Known
root node, schema module/byte, written identity and entry ownership limits are
also admitted before that first read. A private admission token carries the paid
entry spelling, schema and limits into the later capture without charging or
replacing them again. Its schema-source scan reserves work before traversal.
An early refusal retains the exact native cause, request spellings, both schemas
and any preexisting raw captures without fabricating an environment or document.

The original entry is captured and inherited once with its retained schema. A
complete borrowed scan of the original materialized input declarations reserves
its arena work before looking up producer fields. A non-null authored `schema`
selects the graph, including fields contributed by a parent and absent from the
raw entry. Defaults do not invent declarations. The shipped source schema still
rejects explicit `schema: null` with its original REQ-0287 cause. Malformed source
metadata is rejected before selection; compiler error text never drives routing
or retry.

A crate-private capture owner keeps the original document, environment, schema,
resources, written entry and admitted limits together. The ordinary transfer
consumes that complete owner into the existing `PreparedRun` and compiles once
against the retained environment. It ends the metadata-only scope only after
successful preparation and compilation, before later ordinary study authority.
Existing fresh activation, source origins, reports, codecs and explicit held-byte
Save behavior remain. A failed compilation retains its `RejectedRun` beside the
original native resources and entry; bounded evidence or diagnostic refusal does
not discard that owner.

The producer transfer creates the original root Arc once and seeds the iterative
collector with it. The collector neither rereads through a second preparation
path nor supplies a replacement environment. Canonical alias and diamond edges
reuse their one prepared document Arc. Snapshot verification still checks the
original descriptors and aliases, charging its rereads and work. Original schema,
input and output declaration origins remain independently retained. The complete
closure compiles once; core node plans stay private and the static graph refuses
an execution capability. Its existing explicit complete `into_build` transfer
remains available to the qualified private host component, without a graph Save
or publisher.

Environment, entry, recursive capture, snapshot and graph failures retain their
existing typed rejection owners, including raw bytes captured before decode or
inheritance failed. Ordinary compilation rejection is a distinct owned result,
never a fallback path. Retained source evidence borrows immutable held bytes and
admits path ownership before allocation; an oversized request preserves its
original failure and admitted prefix. Reports after file/other-owner deletion
use held evidence without recapture, replay or fabricated dependent attempts.

Independent native witnesses cover ordinary full report compatibility and exact
saved CSV bytes after deletion; inherited ordinary source origins and fresh
activation; active producer aliases and a diamond; original decode/schema,
contract, compiler and cycle causes; environment and recursive quotas; configured
absolute paths and lexical refusal; and original root Arcs through complete build
transfer. The producer witness retains unrounded 1.234/2.345 values separately,
