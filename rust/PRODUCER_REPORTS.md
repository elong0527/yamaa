# Retained producer graph reports

The #1871 report service borrows the complete consumed graph and the exact native
attempt. It introduces no publisher or ordinary Python/R workflow dispatch.
The #1741 installed host and explicit publication gates remain separate.

`PreparedBuild::report_contexts` borrows canonical nodes with their existing
compiled plans. Native `Provenance::report_views` pairs those plans with the
original prepared document, including captured inherited bytes. Its constructor
is private, and `RunView` and `ActivationView` remain sealed. A metadata node
cannot become an arbitrary standalone file plan. Reporting does not replace an
environment, recompile a node, activate a host, execute a handler, decode an input,
encode output or reopen a file.

`FileBuild::build_reported` uses `NativeReport` inside ordinary output preparation.
Selection borrows the complete entered source/execution attempt and admits the
actual node pointer from the retained graph. Source tables, capture counters,
handler counts and completed checks precede output preparation. The qualified
ordinary output declaration and native CSV/Parquet report services then render
complete observations. The complete bounded report must succeed before artifact
bytes become available to a consumer. Failure clears prior selection state and
stops dependent ingestion. An after-build report cannot replace this gate.

`producer_report::attempt_report` renders one union activation and the actual
producer-first entered node prefix. Environment and lock source identities are
retained. Passed activation observations are checked even for interrupted or
incomplete attempts. Completed node reports are borrowed from their accepted
output; failed nodes reuse the ordinary source, check and diagnostic services.
Partial decoded source tables remain visible. Missing counter observations stay
unavailable rather than becoming invented zeros. The result describes complete
or failed evidence only; it exposes no save operation.

Known native resource and ingestion causes retain their portable vocabulary and
authored paths. Producer metadata mismatch retains REQ-0535 and stored field
order; preparation's REQ-0534/REQ-0523 rejection evidence remains unchanged.
Unprojected transport, opaque host and interrupt/unwind failures remain owned by
the exact typed attempt. `ProjectionError::Original` borrows that owner together
with its bounded actual observation prefix. Quota/invalid-observation refusal
leaves the caller's complete attempt intact. Reporting never classifies a native
resource cause by its message or fabricates an unentered dependent.

Count, cell, text, escaping and work capacities precede report ownership growth.
Larger caller budgets cannot exceed the formatter's fixed 16 MiB admission ceiling.
Table shape admission precedes cell access; each generic source cell is read once
and charged before its value is copied. Immutable JSON is charged before cloning.
Activation-origin scans and repeated check metadata lookups also consume work.
Native output datasets are immutable, so their Parquet record preflight cannot
change between admission and rendering. Conservative report capacities are
explicit policies, not normative language limits or allocator/RSS guarantees.

Independent native evidence keeps the unrounded producer table separate from
serialized CSV truth: `1.234/2.345 -> 1.23/2.35 -> 2.46/4.70`. Complete literal
report truth includes both consumer references, the full derived schema and union
activation. Repeated build/reporting, deleted owners/files, failed checks and
sources, original host failures/interrupts/unwind, late report refusal and table
count admission have separate witnesses. Native malformed producer headers
retain their original REQ-0535 diagnostic before typing and refuse report copies
under an insufficient budget.
