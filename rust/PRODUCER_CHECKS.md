# Original producer graph static checks

The #1874 service connects ordinary Python `check(..., environment=...)` and R
`yamaa_check(..., environment=...)` to one native original-document graph
preparation. Public environment paths retain the established absolute-path and
approved-root policy. The shared preparation captures the environment once,
captures the canonical recursive closure through original declaring origins,
and compiles the closure once against that retained environment. It does not
dispatch from a failed compiler result or an error message.

`file_workflow::prepare_with_resources` admits the cumulative metadata scope
before the first environment root read. Graph preparation continues exactly
that policy and its spent bytes, text, snapshots and work. Environment root and
dependency preparation copies are charged before allocation. A larger or
different policy cannot replace a live scope. Failed preparation retains its
original native resources, raw capture prefix, both schema capabilities, typed
environment rejection or graph rejection, and successfully prepared original
documents. Projection and file deletion do not consume this evidence.

The core complete static graph exposes a borrowed finding iterator; its node
compilations stay private. `producer_check` projects findings only from that
complete owner, without converting it into a build, substituting an environment
or compiling a node again. One ordinary external-input node preserves ordinary
check rows. Multiple canonical nodes contribute diagnostics in captured node
order, with canonical node `source` and graph `entry` context. Inherited check
findings additionally retain `declaring_sources` aligned with their paths;
unavailable origins remain null rather than becoming invented facts.

types, workflow cycles, compiler findings and supported schema/inheritance and
