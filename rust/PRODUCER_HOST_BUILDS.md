# Private installed producer build carriers

The private Python and R qualification entry points prepare through `file_workflow`
and consume the complete original recursive closure into one `FileBuild`. They
retain its captured environment, original documents, schema and approved resource
owner. No single-node compilation or replacement environment is introduced.

Each fresh build uses the actual installed host port with the retained lock bytes.
The engine completes union lock verification, binding, conformance and full local
to global signature admission before study inspection or capture. Canonical nodes
execute once in producer-first order. Native verification, output, codec and
complete report gates finish before consumers receive accepted held artifact
bytes. The rounded CSV remains distinct from the retained unrounded table.

Python carriers own the entire attempt through `Arc<Mutex<_>>`; all borrows use
`try_lock`. Registered R external handles own calling-thread `Rc` state and rooted
condition objects. Incoming pointers are looked up as registry identities without
casting a pointee. R reserves a bounded handle slot before preparation, activation
or classification; reentrant callbacks cannot consume the slot needed to return
the entered attempt. Reporting holds an exclusive attempt borrow so reentrant
reads or rendering refuse promptly.

Pure failure visitors borrow union activation failures first, followed by actually
entered node execution failures. Complete graph reports accept ordinary host
classification facts only for the exact retained payload reference. Unrelated,
duplicate, wrong-stage and zero-sized address facts refuse. Count, text, escaping,
context and work admission precede maps, diagnostic copies and host evidence
copies. Authored environment and inherited derivation origins come from the sealed
retained union and original documents. Opaque failures, interrupts, unwind,
retention failures and projection refusals keep the original complete attempt.
Early preparation rejections similarly retain raw evidence and typed diagnostics.

The private carriers expose evidence and reports. They expose no publisher or
Save capability. A failed consumer can retain an earlier accepted producer
artifact as evidence while the whole graph remains failed. Reading that evidence
does not replay activation, execution, encoding, file capture or publication.

Independent installed witnesses use existing `yamaa_benchmarks.project_value` and
`yamaabenchmarks::project_value`, the existing Python lock and hash-free R locks.
They pin raw values 1.234 and 2.345, producer CSV values 1.23 and 2.35, and two
consumer references yielding 2.46 and 4.70. They also cover inherited origins,
aliases and a diamond, repeated fresh activation, consumer-only binding refusal
before data, original exception/interrupt identity, native ingestion and
verification failures, report gates, quotas, reentrancy and owner/file deletion.
The installed suites are component qualification, not public workflow release
qualification.
