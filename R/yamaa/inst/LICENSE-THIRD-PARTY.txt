yamaa third-party notices
=========================

The installed yamaa R package links third-party Rust crates and the Rust
standard library into its native extension. This file lists those crates with
the license, copyright and NOTICE texts that each crate ships, and reproduces
the standard library's notice. The project's own license is in LICENSE.txt;
LICENSE-READSTAT.txt, LICENSE-UNICODE.txt and LICENSE-YAML.txt carry the
notices for the vendored ReadStat sources, the Unicode data in yamaa's own
tables and the vendored saphyr-parser crate.

The list covers every third-party crate in the normal and build dependency
closure of the shipped crate yamaa-r, for every target platform, as locked in
rust/Cargo.lock. Crates that run only while compiling, such as build scripts
and procedural macros, and crates used only on other platforms are listed too.
Crates come from crates.io unless an entry names another source.

Where a crate offers a choice of licenses, yamaa relies on the first license
in this order that the crate offers and whose text the crate ships: MIT,
Apache-2.0, BSD-3-Clause, Unicode-3.0, Apache-2.0 WITH LLVM-exception,
CC0-1.0, Zlib. Each entry names the license relied on. Texts that only grant
an alternative license are not reproduced; the crate's general license,
copyright, NOTICE and AUTHORS files are.

Texts are reproduced verbatim, with LF line endings and a final newline.
Identical texts are printed once and numbered; each entry names the numbered
texts its crate ships. A crate whose package ships no notice, but whose
repository also publishes a listed crate that does, names that crate's texts.
Otherwise, where a crate package ships no text for the license it is relied on
under, the entry says so and the canonical text from the SPDX License List
3.29.0 is reproduced instead, with its placeholders unfilled.

The Rust standard library section reproduces the notice that Rust 1.99.1, the
toolchain that builds the released packages, ships as
share/doc/rust/COPYRIGHT-library.html: the Rust project's licensing statement,
the licenses and copyright holders of the standard library's own files with
the license texts that the toolchain ships in share/doc/rust/licenses, and
every out-of-tree crate used to build the standard library with the notice
texts that the Rust project reproduces for it. That list covers every target
and the tools that build the standard library, so it names crates that the
native extension does not link. Its entries are reproduced as published,
without a choice of license.

This file is generated by tools/packaging/generate_third_party_notices.py from
rust/Cargo.lock and the Rust 1.99.1 toolchain; do not edit it by hand.
