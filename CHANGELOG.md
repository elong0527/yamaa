# Changelog

This file records every normative change: an edit to a rule under
[`yaml/rules/`](yaml/rules/) or to a schema module `yaml/schema*.yaml`.

Entries are written one file at a time under [`changelog.d/`](changelog.d/)
and assembled here when a version is published, so branches that land in
parallel never edit the same lines.
[CONTRIBUTING.md](CONTRIBUTING.md) states the procedure.

The repository has published no release: schema bundle `1.0` is the working
bundle, the repository carries no tag, and the release and compatibility
policy is still open (#104 closed without merging its policy document).
Nothing is assembled here until that policy fixes what a release is and
which changes force a bundle version action.

## Unreleased
