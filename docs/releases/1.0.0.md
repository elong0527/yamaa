# yamaa 1.0.0

yamaa 1.0.0 is in development. These notes are written as it is built, and
become the notes of the 1.0.0 release. The
[0.9.0 notes](https://github.com/elong0527/yamaa/blob/yamaa-v0.9.0/docs/releases/0.9.0.md)
cover the changes released before it.

## Upgrading

- **Rounded values change for written ties of large values.** A normal
  binary64 that is the one nearest a tie of at most fifteen significant digits
  now rounds as that tie, away from zero, wherever the one rounding applies:
  `8753033.315` at two places is `8753033.32`, where it was `8753033.31`. The
  `prohibited_function` hint for `ROUND` states the rounding's tie rule
  (FORMULA-16, CSV-9, TEXT-15, #4864 D-next).
