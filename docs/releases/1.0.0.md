# yamaa 1.0.0

yamaa 1.0.0 is in development. These notes are written as it is built, and
become the notes of the 1.0.0 release. The
[0.9.0 notes](https://github.com/elong0527/yamaa/blob/yamaa-v0.9.0/docs/releases/0.9.0.md)
cover the changes released before it.

## Upgrading

- **A datetime converted from text without seconds is collected to the
  minute.** `2025-03-04T08:30` converted or ingested as a `datetime` now has
  collected precision `minute` and time imputation flag `S`, as `impute` gives
  it, where it was `second` with no flag (TIME-7, VALUE-16, #4879 D-next).
