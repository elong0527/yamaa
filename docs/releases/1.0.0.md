# yamaa 1.0.0

yamaa 1.0.0 is in development. These notes are written as it is built, and
become the notes of the 1.0.0 release. The
[0.9.0 notes](https://github.com/elong0527/yamaa/blob/yamaa-v0.9.0/docs/releases/0.9.0.md)
cover the changes released before it.

## Changes

- The lint reports `window_tie`: a `locf`, `row_value` or `row_number` window
  whose `group_by` and `order_by` terms leave out a declared key, so a carried
  or neighbouring value depends on the order of the input records (#4877,
  D-next). Runs are unchanged.
