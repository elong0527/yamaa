# yamaa 1.0.0

yamaa 1.0.0 is in development. These notes are written as it is built, and
become the notes of the 1.0.0 release. The
[0.9.0 notes](https://github.com/elong0527/yamaa/blob/yamaa-v0.9.0/docs/releases/0.9.0.md)
cover the changes released before it.

## Upgrading

- **Break: R `run(inputs = ...)` refuses a `POSIXct` column whose `tzone` is
  not `"UTC"` or `"GMT"`**, including the session's zone, where it shifted the
  clock times to UTC; convert with `lubridate::force_tz(x, "UTC")` (#4882
  D-next).
- **Published values change for a constant group.** A group whose non-missing
  values are all equal now gives `MEAN` that value and `STDDEV` and `VARIANCE`
  exactly `0`, where the ordered sum could leave a last-place error: six
  values of 4.1 gave a mean of `4.1000000000000005` and a `STDDEV` near
  `1e-15`, so a `NULLIF(sd, 0)` guard never fired (FORMULA-19, FORMULA-24,
  #4859 D-next).

## Changes

- The `duplicate_key` and `unique_failed` messages name the unit they count,
  repeated key combinations, not rows: "the output keys repeat for 1 of their
  distinct combinations" (OUTPUT-3, CHECK-10, #4857 D-next).
- **R `run(inputs = ...)` converts a character or factor column without a
  per-value R call**, under a second for a million rows, and a refused value
  names its column, row and bytes (#4883).
