# yamaa 1.0.0

yamaa 1.0.0 is in development. These notes are written as it is built, and
become the notes of the 1.0.0 release. The
[0.9.0 notes](https://github.com/elong0527/yamaa/blob/yamaa-v0.9.0/docs/releases/0.9.0.md)
cover the changes released before it.

## Changes

### Rows, lookups and relations

- **Break: in a specification without `rows`, an unfiltered `source` read
  of the base records refuses `absent`.** A row is built from at least one
  base record, so the `absent` answered nothing; it now fails as
  `prohibited_construct`, as it does in a specification that declares `rows`.
  The refusal of `absent`, `require_match` or `between` on such a read now
  says the read "always finds a value" (LOOKUP-24, #4995 D405).
- **A selection over a row's base records that chose nothing is a warning
  of the run report.** In a specification without `rows`, a `source`
  binding's `order_by` and `keep` that met no row whose records read two
  values, as when the keys are at the grain of the base's records, is
  reported as an `unchosen_selection` warning row; the run still succeeds
  and no value changes (LOOKUP-10, #4995 D405).
