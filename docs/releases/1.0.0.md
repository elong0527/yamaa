# yamaa 1.0.0

yamaa 1.0.0 is in development. These notes are written as it is built, and
become the notes of the 1.0.0 release. The
[0.9.0 notes](https://github.com/elong0527/yamaa/blob/yamaa-v0.9.0/docs/releases/0.9.0.md)
cover the changes released before it.

## Upgrading

- **A filtered `source` read that keeps no record answers its `absent`.**
  On a read of the row's own driver records, a row template's included, a
  `filter` that keeps none of them now gives the binding's declared `absent`
  value and counts it under `absent`, where it gave missing and counted
  nothing (NAME-6, COLUMN-12, LOOKUP-24, #4922 D-next).
