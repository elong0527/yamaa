# yamaa 1.0.0

yamaa 1.0.0 is in development. These notes are written as it is built, and
become the notes of the 1.0.0 release. The
[0.9.0 notes](https://github.com/elong0527/yamaa/blob/yamaa-v0.9.0/docs/releases/0.9.0.md)
cover the changes released before it.

## Upgrading

- **An in-memory input names the column it refuses**: an unsupported type or
  a value off a whole second reports the frame's `column`, its Arrow `type`
  and a value's `record` where it reported a `value`; a column of another type
  than the input declares fails as `incompatible_input_type` at
  `inputs.<alias>`, where it failed as `engine_rejected`; and a column with no
  value is missing in its declared type (SCHEMA-12, INPUT-5, #4881, D-next).
