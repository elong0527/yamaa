# yamaa 1.0.0

yamaa 1.0.0 is in development. These notes are written as it is built, and
become the notes of the 1.0.0 release. The
[0.9.0 notes](https://github.com/elong0527/yamaa/blob/yamaa-v0.9.0/docs/releases/0.9.0.md)
cover the changes released before it.

## Changes

### Refusals that say what to fix

- **An expression nested past the depth limit is refused at its field.** A
  derivation, predicate or aggregate text, or the pattern inside one, deeper
  than 128 levels reports `compiler_limit` at its specification path and line,
  as a verb's `pattern` already did, where it reported `resource_limit` in an
  `inheritance_` phase with no path or line (LIMIT-1, #4890 D-next).
