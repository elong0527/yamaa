# yamaa 1.0.0

yamaa 1.0.0 is in development. These notes are written as it is built, and
become the notes of the 1.0.0 release. The
[0.9.0 notes](https://github.com/elong0527/yamaa/blob/yamaa-v0.9.0/docs/releases/0.9.0.md)
cover the changes released before it.

## Changes

### Values and types

- **A constant group has `STDDEV` and `VARIANCE` 0 and means its value.** A
  group whose non-missing values are all equal now gives `MEAN` that value
  and `STDDEV` and `VARIANCE` exactly `0`, where the ordered sum could leave a
  last-place error: six values of 4.1 gave a mean of `4.1000000000000005` and
  a `STDDEV` near `1e-15`, so a `NULLIF(sd, 0)` guard never fired (FORMULA-19,
  FORMULA-24, #4859 D-next).
