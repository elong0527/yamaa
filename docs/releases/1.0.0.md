become the notes of the 1.0.0 release. The
[0.9.0 notes](https://github.com/elong0527/yamaa/blob/yamaa-v0.9.0/docs/releases/0.9.0.md)

## Upgrading

- **`duration_text` writes a `float` amount's collected duration.** The
  amount's shortest digits are scaled to seconds exactly, so `1.1` hours is
  `PT1H6M` where it was `PT1H6M0.0000000000005S`, and `0.12` minute is
  `PT7.2S` (TIME-21, #4860 D-next).
