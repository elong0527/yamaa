# harbor-benchmark-findings-2026-10-04 slides

"Harbor benchmark findings" -- how prompt completeness drives agent
success on CDISC derivations, from the Harbor agent-benchmark runs on
yamaa (2026-10-04).

[View the rendered slides](https://elong0527.github.io/yamaa/slides/harbor-benchmark-findings-2026-10-04/index.html)

## Files

- `index.qmd` -- the deck (results table, three verbatim prompt examples)
- `custom.css` -- the deck's single style file

## Build

The HTML is built by the Deploy docs GitHub Action and published with the
docs site. To preview locally: `quarto render index.qmd` from this folder.
The output is one self-contained HTML file (`embed-resources: true`).
