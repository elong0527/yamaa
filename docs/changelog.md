# Changelog

YAMAA does not keep a separate changelog file in this repository. Changes are
tracked through the commit history and pull requests:

- [Commits on `main`](https://github.com/elong0527/yamaa/commits/main)
- [Pull requests](https://github.com/elong0527/yamaa/pulls?q=is%3Apr)
- [Releases](https://github.com/elong0527/yamaa/releases), when published

The normative language surface -- rules in
[`yaml/rules/`](https://github.com/elong0527/yamaa/tree/main/yaml/rules), the
schema bundle in [`yaml/`](https://github.com/elong0527/yamaa/tree/main/yaml),
and the runnable benchmarks in
[`benchmark/`](https://github.com/elong0527/yamaa/tree/main/benchmark) --
is versioned in git alongside this documentation.
