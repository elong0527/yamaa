# Benchmark Overview

The [benchmark dashboard](https://elong0527.github.io/yamaa/benchmark/) 
provide benchmark for yamaa to assess human and AI collaboration. 

| Group | What it is |
|---|---|---|
| `schema-*` | Assess yamaa schema  |
| `adam-*` | Assess SDTM to ADaM derivations |
| `sdtm-*` | Assess ODM to SDTM derivations |
| `negative-*`| Assess yamaa error handling |

The suite serves multiple audiences at once:

* **User** read it as a cookbook.
* **Developer** run it as a test.
* **AI agents** learn common use cases and anti patterns.
