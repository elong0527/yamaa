README

What this example means

This example uses collected adverse events to attempt one record per event:

  • ASTDT is the date the event started.

One start date was collected as a month without a day. A date identifies one day, so choosing the first of the month, the last, or the middle would each answer with a day nobody recorded. Completing a partial date is a rule a specification states deliberately, and this one states none, so the run must fail and no artifact is accepted.

How to fix

Declare how a partial date is completed. For example, to use the earliest date the collected text permits:

derivation:
  date_impute:
    source: AE.AESTDTC
    month: 1
    day: 1

A complete source date is retained; 2023-06 becomes 2023-06-01.
